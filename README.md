# IPL Data Analysis Project (2008 - 2024)

## Project Overview
This project performs a deep data analysis on the IPL ball-by-ball dataset. I have used Python and its powerful data science libraries to uncover interesting patterns about top batsmen, best bowlers, and match statistics.

## Tech Stack Used
- Python
- Pandas (Data Manipulation)
- NumPy (Numerical Operations)
- Matplotlib (Data Visualization)

## Key Insights Uncovered
- Found the Top 5 highest run-scorers in IPL history.
- Analyzed the worst-performing batsmen with the least runs.
- Visualized the final results using beautiful Bar Charts.

## How to Run This Project
1. Clone this repository.
2. Install dependencies: `pip install pandas matplotlib`
3. Open `analysis.ipynb` in VS Code and run all cells.
